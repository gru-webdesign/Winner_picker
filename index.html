Preuzimanje komentara

Komentare preuzima Apify scraper. Izaberi jedan način: preko svog servera (token ostaje skriven) ili direktno sa svojim Apify tokenom u ovom pregledaču.

Cloudflare Worker iz foldera worker/. Ako je popunjeno, token ispod se ne koristi.

console.apify.com → Settings → API & Integrations. Čuva se samo u ovom pregledaču.

Apify naplaćuje oko $2,6 na 1.000 komentara. Besplatnih $5 mesečno pokriva oko 1.900.
